🏭 Enterprise Manufacturing KPI Intelligence System

Project Overview

An enterprise-grade, end-to-end Manufacturing Intelligence Platform integrating Safety, Quality, Energy, Water, Production, Maintenance, and Supply Chain data into a unified KPI reporting system used by COO-level leadership across 3 plants for real-time daily decision-making.

Architecture

SharePoint + Excel + SAP + IoT Chipster
 → SQL Server (Cleaning & Validation)
 → Power Query ETL
 → Star Schema Data Model
 → DAX KPI Layer (50+ measures)
 → Power BI Dashboards
 → On-Premises Gateway (Automated Refresh)

Key Features

  • SQL-based data validation and transformation across 6 source systems
  • Automated ETL pipelines using Power Query with append/merge queries
  • Enterprise star schema optimized for reporting performance
  • 50+ DAX KPIs across Safety, Quality, Production, Maintenance, and Supply Chain
  • Fully automated dataset refresh via Power BI Gateway — failure alerts to owner

KPI Domains Covered

  • Safety: Dept-wise incidents, HMS identified vs closed, RIR trends
  • Quality: Internal & external complaints, rejection %, NCs, defect trends
  • Energy: Renewable generation, EB vs DG usage, process-wise kWh
  • Production: Daily output, OEE, AU, throughput, yield, rejection analysis
  • Maintenance: Downtime, MTBF, MTTR, breakdown trend analysis
  • Supply Chain: Inventory days, OTIF, sales (₹ Cr / MT), dispatch tracking
  • Water: Source-to-use flow, consumption, losses & rejections

Technology Stack

SQL Server Power BI DAX Power Query Python SAP SharePoint On-Premises Gateway
