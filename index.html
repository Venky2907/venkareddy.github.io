🏭 Enterprise Manufacturing KPI Intelligence System

✅ Project Overview

An enterprise-grade, end-to-end Manufacturing Intelligence Platform that integrates Safety, Quality, Energy, Water, Production, Maintenance, and Supply Chain data into a unified KPI reporting system.
The solution provides real-time, plant-level performance visibility to leadership teams, eliminating manual reporting and enabling standardized, data-driven decision-making.

✅ Architecture

SharePoint + Excel + CSV → SQL Server (Cleaning & Validation) → Power Query ETL → Star Schema Data Model → DAX KPI Layer → Power BI Dashboards → On‑Premises Gateway (Auto Refresh)

✅ Key Features

  • SQL-based data validation and transformation
  • Automated ETL pipelines using Power Query
  • Enterprise-scale star schema for optimized reporting performance
  • 50+ DAX KPIs across Safety, Quality, Production, Maintenance, and Supply Chain
  • Fully automated dataset refresh using Power BI Gateway (no manual intervention)

✅ Business Domains & KPIs

  • Safety: Department-wise incidents, HMS identified vs closed, RIR trends
  • Quality: Internal & external complaints, rejection %, NCs, defect trends
  • Energy: Renewable generation, EB vs DG usage, process-wise kWh usage
  • Production: Daily output, OEE, AU, throughput, yield, rejection analysis
  • Maintenance: Downtime, MTBF, MTTR, breakdown trend analysis
  • Supply Chain: Inventory days, OTIF, sales (₹ Cr / MT), dispatch tracking
  • Water Management: Source-to-use flow, consumption, losses & rejections

SQL Server Python Power BI Power Query DAX SharePoint Excel
